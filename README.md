# סרטון קונימבו / יוליפ

סרטון השקה בעברית ליוליפ, בשתי גרסאות (60 שניות ו־2 דקות), עם קריינות.

## מבנה
- `youleap-2min-voice-v5c.mp4` גרסת 2 הדקות
- `output/` גרסת 60 השניות, התסריט ותוכנית הסצנות
- `video/site/` עמוד ה־HTML שממנו מרונדר הסרטון (סצנות, אנימציות, תזמונים ב־cues.js)
- `video/site/portal/` צילומים סטטיים של פורטל הטאבלטים, עם נתוני דמו בלבד
- `video/render.py` רינדור פריים־פריים עם Playwright ו־ffmpeg
- `video/synth.py`, `voicemix2.py` מוזיקה ומיקס קריינות
- `tts/` יצירת הקריינות (Phonikud + Piper, קול "שאול")

## הערות
- קבצי המודל של הקריינות (onnx) לא נכללים, הם כבדים ומורדים מ־Hugging Face.
- רישיון קוד הקריינות לשימוש לא מסחרי. לגרסה שיוצאת ללקוחות כדאי להחליף לקול מוקלט או לשירות מסחרי.
