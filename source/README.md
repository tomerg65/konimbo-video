# source: הקבצים שמהם הסרטון נבנה

התיקייה הזאת נדרשת רק למי שרוצה לשנות משהו בסרטון. לצפייה, הסרטונים המוכנים נמצאים בתיקייה `videos` בראש המאגר.

| תיקייה | מה יש בה |
|---|---|
| `scenes/` | `index.html` מכיל את כל הסצנות. `cues.js` קובע מתי כל דבר מופיע, לפי הקריינות. |
| `scenes/portal/` | מסכי הפורטל (לוח בקרה, לקוחות בסיכון, עוזר AI, לקוח 360, קטלוג, תובנות, שיווק), עם נתוני דמו. |
| `scenes/assets/` | לוגו יוליפ, לוגואים של לקוחות, תמונת המחסן והפונטים (Heebo). |
| `render/` | `render.py` מצלם את העמוד פריים אחרי פריים והופך אותו לסרטון. `qa.py` בודק שאין רגעים קפואים או מסכים שחורים. |
| `audio/` | `synth.py` יוצר מוזיקה. `voicemix2.py` משלב את הקריינות במקום הנכון. `timing/` שומר את התזמונים. |
| `voice/` | יצירת הקריינות: `lines_v2.py` הוא התסריט של גרסת 2 הדקות, `gen2.py` מייצר ממנו קבצי קול, כולל תיקוני ההגייה. |

קבצי מודל הקול (`.onnx`) לא נמצאים כאן כי הם כבדים. מורידים אותם מ־Hugging Face: `thewh1teagle/phonikud-onnx` ו־`thewh1teagle/phonikud-tts-checkpoints`.
